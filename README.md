# Курсова робота

Тема:
Довідник меломана

База груп і виконавців(містить назву, країну, рік заснування, жанр та короткий опис); база пісень(містить назву композиції, тривалість, мову виконання та посилання на ID виконавця); база дисків(містить назву альбому, рік випуску, лейбл та перелік пісень у вигляді посилань (ID) на об'єкти з бази пісень). Вибір всіх пісень заданої групи; всіх дисків, де зустрічається задана пісня. Додавання, видалення та редагування об’єктів у кожній з трьох колекцій (виконавці, пісні, диски). При редагуванні виконавця дані автоматично оновлюються для всіх пов'язаних з ним пісень. Всі три бази даних (групи, пісні, диски) зберігаються в окремому локальному файлі (або декількох структурованих файлах). Це забезпечує збереження всієї структури зв'язків та посилань між роботою програми.
